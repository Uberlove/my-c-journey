TIPOS PRIMITIVO E TABELA DE BYTES/BITS.

São 4 tipos básicos para definir uma variável.

CHAR tem 1 byte ou 8 bits com um intervalo de valores entre -128 e 127, serve para caracteres e números pequenos.
INT tem 4 bytes ou 32 bits com um intervalo de valores entre -2.147.483.648 e 2.147.483.647, usa para números inteiros.
FLOAT tem 4 bytes ou 32 bits com um intervalo de valores entre 1,175494E-038 e 3,402823E+038, usa para números com virgula.
DOUBLE tem 8 bytes ou 64 bits com um intervalo de valores entre 2,225074E-308 A 1,797693E+308, tem mais precisa para números com virgula.

PRECISÃO

FLOAT 6 dígitos.
DOUBLE 15 dígitos.
LONG DOUBLE 19 dígitos.

Tipos não tão básicos.

UNSIGNED usa valores positivos.

UNSIGNED CHAR 1 byte/8 bits com intervalo entre 0 e 255.
SHORT INT 2 bytes/16 bits com intervalo entre -32.768 e 32.767.
UNSIGNED SHORT 2 bytes/ 16 bits com intervalo entre 0 e 65.535.
UNSIGNED INT 4 bytes/ 32 bits com intervalo entre 0 e 4.294.967.295.
LONG INT 4 ou 8 bytes/ 32 ou 64 bits com intervalo entre -2.147.483.648 e 2.147.483.647 / -9.223.372.036.854.775.807 e 9.223.372.036.854.775.807.
UNSIGNED LONG LONG 8 bytes com intervalo entre 0 e 18.446.744.073.709.551.615.
